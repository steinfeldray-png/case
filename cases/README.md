# Кейсы

Новый кейс: папка `cases/<slug>/` с `case.json` и картинками. Пуш в `main` публикует изменённые кейсы и пересобирает сайт.

Поля `case.json` те же, что в форме админки: `slug`, `title`, `product`, `platform`, `description`, `year`, `challenge`, `solution`, `results`, `tags`, `imageUrl`, `caseImages`, `inProgress` и версии с суффиксом `En`. В `imageUrl` и `caseImages` можно указать имя файла из папки кейса.
